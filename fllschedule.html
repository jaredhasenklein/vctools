FLL Schedule Generator Beta

Build judging and robot game schedules for a FIRST LEGO League Challenge event.

How to use
  1. Enter team numbers, or click Use pit numbers instead to number teams 1 to N.
  2. Adjust durations, rooms, tables, rounds, and lunch to match your event.
  3. Click Generate Schedule, check the end times, then Download the Excel file.

Beta: check the schedule before publishing it. Each run shuffles teams, so generate again for a different order.
